# Результаты проверки на фотографиях

После завершения сканирования учитель видит проверенные работы в отдельной таблице на странице «Мои работы». Новые результаты появляются автоматически. Открытая работа показывает отправленные фотографии и пронумерованные области ошибок с пояснениями.

## Решение

Использовать существующий авторизованный `GET /api/v1/batches/{batchId}/results`: backend читает Redis cache с PostgreSQL fallback. Новый results composable читает все сохранённые проверки текущего учителя из IndexedDB и обновляет незавершённые партии каждые 2500 мс. Параметр `scanId` или старый `batchId` ограничивает выборку; отсутствие ID показывает все проверки.

Сохранять cursor и результаты до ACK через существующий BatchWorkflow. Не подтверждать получение автоматически. ACK не удаляет локальные фотографии. Перезапуск страницы восстанавливает завершённые сессии; результаты другого учителя не показываются.

Фото сопоставляется по batchId/taskId и по точному page_id из result.pages, если он есть. Используется preparedBlob ?? blob — байты, отправленные на проверку. result.boxes содержит координаты 0–1000 и номер страницы; при изменении размера фотографии обводки масштабируются вместе с ней. Отсутствие координат отображается явно, без выдуманных областей. Для клетки status=manual сохраняется требование учительской проверки, а предложение AI показывается отдельно.

## Подходы

Выбран готовый batch API и локальные фото: минимальная совместимая интеграция. Прямой доступ браузера к Redis требует раскрытия инфраструктуры и не нужен. Новый серверный архив фотографий меняет жизненный цикл хранения и выходит за рамки этой задачи.

## Ограничения

- Nuxt, Vuetify и текущие цвета; без новых продуктовых зависимостей.
- Существующие scanner capture/finish и ручное подтверждение остаются рабочими.
- История с фото доступна в браузере, в котором сканировали.
- Исправить AI worker: поиск координат выполняется до замены диагностических статусов на manual.
- Пользователь попросил быструю реализацию без дополнительного обсуждения; решения выше приняты исполнителем.
